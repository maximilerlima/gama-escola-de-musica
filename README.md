# Gama Escola de Música

Site da Gama Escola de Música, no Grajaú, Rio de Janeiro. Feito em HTML, CSS e JavaScript, com imagens WebP otimizadas para diferentes tamanhos de tela.

## Publicação

O GitHub Pages é publicado automaticamente pela GitHub Action em `.github/workflows/deploy-pages.yml` sempre que há um envio para a branch `main`. O endereço planejado é https://maximilerlima.github.io/gama-escola-de-musica/.

## Atualizações

Envie os arquivos do site para a branch `main`; a Action prepara o conteúdo estático e faz a publicação. As imagens em alta definição e as versões menores ficam em `assets/`.
